# Schema summary

Generated by hand from `schema.prisma` and the `20261118202744_init` migration
(including its hand-written additions). Factual reference, not a tutorial.
Regenerated after the approval-time amendments in docs/decisions.md D14 — the
original `20261118201529_init` folder was deleted (never applied) and
replaced by this one.

All tables except `organizations` have a NOT NULL `organization_id UUID` FK to
`organizations.id` (RESTRICT) — omitted from each table's column list below to
avoid repetition, but included in every table's own listing anyway since it's
a real column. All `id` columns are `UUID NOT NULL`, primary key, generated as
UUIDv7 **by the Prisma Client at insert time** (no DB-level default — see
docs/decisions.md D13). All FKs are `ON DELETE RESTRICT ON UPDATE CASCADE`.
