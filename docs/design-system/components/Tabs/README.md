# Tabs

Switch between views of the same record (lead, project, employee) without leaving the page.

- Underline style: active tab `ink` text with a 2px `primary` underline; inactive `ink-muted`.
- Optional count after the label in 12px `ink-muted`.
- 2–6 tabs; labels one or two words. More than 6 → use a sidebar section instead.
- Keyboard: arrow keys move between tabs, `role="tablist"`/`role="tab"`/`aria-selected`.
